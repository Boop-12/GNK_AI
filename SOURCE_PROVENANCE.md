# Source provenance

This repository reuses the Next.js and FastAPI source from
https://github.com/Boop-12/gnk-algo.git, reference commit
`9d9a3528fd93b73687118e549584f09fab69d6b5`.

The baseline includes the reference checkout's uncommitted broker configuration
and status work as it existed on 8 October 2026. The original checkout was not
edited, committed, reset, or repointed. Existing code and its attribution were
preserved; no LICENSE file was present in the supplied source. Reuse relies on
the owner's authorization in this session, not an invented open-source license.

The supplied FINALGNK_Logo.jpg is preserved as frontend/public/gnk-algo-brand.jpg.
The compact text mark and favicon are new derivatives used for navigation;
the original artwork remains unchanged. No broker credentials, environment
secrets, dependencies, database files, or generated builds were copied.

This is a first implementation milestone, not every future feature in the
planning reference. TOTP, verified broker adapters, live feeds, order execution,
automated strategies, API keys, and webhooks remain unavailable.
